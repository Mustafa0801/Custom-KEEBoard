# Custom-KEEBoard

I created a normal and basic keyboard for this project. It does not have any extra parts like LEDs (though I did try to add those initially).  
  \
This project was my first experience with hardware like PCBs, microcontrollers, how to wire things together and stuff like that.
I've always been more interested in the software side of things however making a keyboard, albeit with a LOT of help, was still really fun.
It showed me how complex things really are that allow us to do the simple tasks we're so used to, even now as I'm typing this it's only possible because of the technical ingenuity of those who created and designed the keyboard.  
  \
The main issues I faced in this project was how overwhelming things felt at times, using new software and reading paragraphs of things which make no sense to you at all.
But in the end I'm quite happy with what I was able to achieve, even though it was a simple keyboard for my first adventure into this field.
